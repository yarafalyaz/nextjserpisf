# Anti-Slop Audit Report: YaraERP (`silengkap`)

- **Audit ID**: audit-001-2026-11-10
- **Mode**: Mode 2 (AFTER)
- **Target**: Seluruh sistem ERP YaraERP (`src/app/`, `src/components/`, `src/lib/`)
- **Tujuan**: Mengidentifikasi pola AI slop, pelanggaran Hard Gate, Purpose-Gate, dan Quality Locks berdasarkan spesifikasi rules `antislop` (R-01 s/d R-40).

---

## Ringkasan Eksekutif

Sistem YaraERP (`silengkap`) secara arsitektur sangat solid dan fungsional:
- Memiliki validasi data mendalam dan sistem akuntansi/ERP nyata (bukan sekadar mockup/prototipe).
- Tidak ditemukan kata kunci marketing klise AI generik (*"AI Powered", "Revolutionary", "Cutting-edge", "Seamless"*).
- Tidak ditemukan tombol atau aksi palsu (*"Get Started", "Learn More"* generic CTA).
- Tidak ditemukan dependensi gradient biru-ungu generik khas AI atau background grid dot/blueprint tanpa fungsi.
- Navigasi terkoneksi 100% ke halaman nyata tanpa tautan kosong (didukung ratchet test `navigation-targets`).

Namun demikian, audit menemukan beberapa pelanggaran spesifik terhadap aturan baku `antislop`, terutama terkait **Hard Gate (R-02 Em Dash di teks UI)** dan beberapa rincian **Interaction Affordances & A11y (R-39, R-32)**.

---

## Daftar Temuan Bernomor (Numbered Findings)

### Tier 1: Hard Gate (Priority: HIGH)

#### [Finding #1] R-02: Penggunaan Karakter Em Dash (`—`) pada Teks UI dan Placeholder Nilai Kosong
- **Pelanggaran**: Rule R-02 (Hard Gate: absolute, no exceptions). Melarang karakter em dash (`—`) dalam teks UI yang ditampilkan ke pengguna.
- **Lokasi Terdeteksi**:
  1. **Placeholder fallback kosong**: Pada tabel dan halaman detail (mis. `src/app/(dashboard)/sdm/pinjaman/_components/loan-table.tsx`, `employee-loan-recap-table.tsx`, `permintaan-gudang/[slug]/page.tsx`), fallback untuk data kosong memakai string `"—"`. Aturan antislop menyarankan penggantian dengan tanda strip/hyphen biasa (`"-"`), atau teks keterangan yang jelas seperti `"Tidak ada"`.
  2. **Teks dialog konfirmasi / feedback UI**:
     - `src/components/ui/reverse-payment-button.tsx:75`: `"Pembayaran ditandai dibalik... Baris asal tetap tersimpan sebagai histori — bukan dihapus."`
     - `src/components/ui/invoice-items-editor.tsx:502, 603, 671, 787`: Label item dan serial validation text: `${ai.name} (${ai.sku})${ai.isScrapSaleItem ? " — Besi Tua" : ""}` dan `" — belum sama qty"`.
     - `src/components/ui/posted-lock-notice.tsx:39`: `"{documentLabel} terkunci — sudah posted"`.
     - `src/app/(dashboard)/aset/_components/asset-analytical-status.tsx:7-10`: `"Nilai buku sudah mencapai nilai residu — tidak ada beban periode ini."`, dll.
- **Rekomendasi**: Ganti karakter `—` menjadi tanda koma `,`, titik dua `:`, tanda hubung `-`, atau tanda kurung `()` sesuai konteks agar terasa natural dan sesuai kaidah R-02.

---

### Tier 2: Purpose-Gate (Priority: MEDIUM)

#### [Finding #2] R-04: Konsistensi Ikon Lucide Tanpa Pernyataan Tujuan (Icon Set Default Fallback)
- **Pelanggaran**: Rule R-04 (Purpose-Gate). Melarang penggunaan ikon library Lucide thin-rounded sebagai default estetika visual semata tanpa relevansi fungsional yang eksplisit.
- **Detail**: Seluruh navigasi dan modul dashboard menggunakan rangkaian `lucide-react`. Meskipun secara semantik ikon yang dipilih sudah sesuai fungsinya (mis. `ShoppingCart` untuk pembelian, `FileText` untuk faktur, `Building2` untuk master), belum ada `DESIGN.md` yang menyatakan pedoman ikonografi resmi proyek.
- **Rekomendasi**: Pertahankan ikon yang sudah representatif terhadap domain bisnis ERP, dan dokumentasikan dial & bahasa desain ikon ini ke dalam `DESIGN.md`.

#### [Finding #3] R-10: Penggunaan Efek Glassmorphism (Backdrop Blur)
- **Pelanggaran**: Rule R-10 (Purpose-Gate). Glassmorphism harus memiliki batasan dosis (dose cap) maksimal pada 1-2 elemen utama per layar dan tidak boleh digunakan bertumpuk.
- **Lokasi Terdeteksi**:
  - `src/components/layout/header.tsx:39` (`backdrop-blur-xs`)
  - `src/app/(auth)/kebijakan-privasi/page.tsx:22` (`backdrop-blur-sm`)
  - `src/app/(auth)/ketentuan-layanan/page.tsx:22` (`backdrop-blur-sm`)
  - `src/app/(dashboard)/pengaturan/peran/[slug]/modul/_components/permission-matrix.tsx:92` (`backdrop-blur`)
- **Evaluasi**: Penggunaan masih berada di dalam batas toleransi dosis (hanya sticky header dan sticky table header untuk menjaga keterbacaan konten di bawah scroll), sehingga **VALID & LULUS Purpose Test**. Perlu dicatat dalam dokumentasi agar tidak ditambah secara berlebihan ke card atau modal.

---

### Tier 3: Quality Locks & Craftsmanship (Priority: LOW)

#### [Finding #4] R-37: Ketidakhadiran Dokumen `DESIGN.md` di Root Repository
- **Pelanggaran**: Rule R-37 (Hard Gate / Quality Lock). Membangun atau mengaudit UI memerlukan panduan arah gaya (`DESIGN.md`). Tanpa panduan ini, sistem berisiko jatuh ke status *"draft without direction"*.
- **Detail**: Saat ini repo memiliki `AGENTS.md`, tetapi belum memiliki file `DESIGN.md` yang menetapkan dial identitas visual YaraERP (tipe industri otomotif/manufaktur/distribusi, kontras palet warna netral/slate, densitas informasi tinggi khas ERP enterprise, tipografi antarmuka).
- **Rekomendasi**: Buat file `DESIGN.md` ringkas yang mencatat keputusan desain antarmuka YaraERP: density, palette role, status badges, typography scale, dan button affordances.

#### [Finding #5] R-39: Penegakan Global `cursor: pointer` pada Seluruh Elemen Interaktif
- **Pelanggaran**: Rule R-39 (Accessible Semantics & Interaction Affordances). Memerlukan semua elemen interaktif (`button`, `a[href]`, `select`, `label[for]`, role switch/tab) untuk memiliki `cursor: pointer` yang diatur langsung pada lapisan CSS dasar global.
- **Detail**: Pada `src/app/globals.css`, class `.form-input` sudah menangani fokus dan disable, namun beberapa custom interaktif mengandalkan utilitas individual Tailwind (`cursor-pointer`).
- **Rekomendasi**: Pastikan rule base CSS global secara eksplisit mendefinisikan cursor affordance:
  ```css
  @layer base {
    button, a[href], select, label[for], [role="button"], [role="tab"], [role="switch"] {
      cursor: pointer;
    }
    :disabled, [aria-disabled="true"] {
      cursor: not-allowed;
    }
  }
  ```
